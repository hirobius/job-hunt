# Portfolio + Learning Plan — Design Technologist / Applied AI Engineer

> North star: **the portfolio is the hiring currency.** Certs are supporting,
> structured learning — and every cert here is chosen so it *produces a
> portfolio artifact*, not just a line on a resume. Hiring managers spend
> ~2–3 min on a portfolio and weigh shipped work alongside (above) credentials.

This is **track #2** (design/AI). Keep it separate from the cleared/govcon-IT
track — different resume, different pitch.

---

## Part 1 — Portfolio: 4 pieces, in priority order

Each piece doubles as **proof + a learning vehicle.** Write every one up the
same way: **Problem → Approach → Key decisions/tradeoffs → Outcome → What I'd
do next.** Process > pixels — show how you think.

### Piece 1 — "Apply Board" case study  *(highest ROI; mostly done)*
You already shipped this in production React + MUI + Supabase. Just **polish +
write it up.**
- Proves: design-eng (shipped React/TS, design system thinking) **and** applied-AI literacy (you directed an AI-built product).
- Do: a clean case-study page — the problem, the architecture, 3–4 decisions (token-based theme, shared store, offline-first + cloud sync), screenshots, live link.
- Effort: **~1 week.** This is your fastest credible artifact.

### Piece 2 — Design-system case study  *(design-eng depth)*
Document the **Hirobius design system** (or rebuild a focused slice): tokens,
components, accessibility, docs, a Storybook.
- Proves: the core design-technologist skill — design *and* maintain a system in code.
- Effort: **~1–2 weeks** (you have the material).

### Piece 3 — An applied-AI product  *(the AI-engineer proof)*
Build **one** small but real LLM product, deployed, with the things hiring
managers actually probe:
- LLM + **RAG** (retrieval over your own docs), **tool-use/agents**, a real UI, and a lightweight **eval** (how you measured quality).
- Idea that fits you: an "AI portfolio/案例 assistant," a design-system-aware code helper, or a résumé↔JD tailoring tool (you already know that problem).
- Proves: you can wire AI into a product and reason about quality — the applied-AI bar.
- Effort: **~2–3 weeks**, built alongside Track B below.

### Piece 4 — Portfolio site + 2 interactive prototypes  *(the meta proof)*
The site itself is your design-technologist audition. Plus 2 small **interactive**
prototypes (motion, a novel interaction) — not static shots.
- Proves: taste + front-end craft in one glance.
- Effort: **~1 week** for the site (host the 4 pieces), prototypes ongoing.

## Part 2 — Learning plan (tandem certs), sequenced

Two parallel tracks + light foundations. Order chosen so each step **feeds a
portfolio piece.**

### Foundations (do first, quick)
- **Python, enough to be dangerous** — you're JS-strong; most AI stacks lean Python. A week of fundamentals + the OpenAI/Anthropic SDKs.
- **Azure AI-900 (AI Fundamentals)** — ~$99, ~1–2 weeks. Easy win, leverages your Microsoft background, warms up for AI-102.

### Track A — Design Engineer (produces Pieces 2 & 4)
- **freeCodeCamp** (free): Responsive Web Design → JS Algorithms → Front-End Libraries (React). Certs are free and the projects *are* portfolio fodder.
- Optional anchor: **Meta Front-End Developer Professional Certificate** (Coursera, ~$49/mo, financial aid available) if you want a recognizable name.
- Skill focus: React + **TypeScript** + Next.js, design tokens, accessibility, animation (Framer Motion).

### Track B — Applied AI (produces Piece 3)
Practical first (these are the skills, and they build Piece 3):
- **DeepLearning.AI short courses** (free/cheap): Prompt Engineering → LangChain for LLM App Dev → **RAG** → **AI Agents** → **Evals**.
- **Hugging Face** LLM course + Agents course (free).

Then the **anchor credential** (pick ONE):
- **Microsoft Azure AI Engineer Associate (AI-102)** — *recommended.* Exam ~$165, deeply relevant (Azure OpenAI, RAG, agents, MLOps), and your Microsoft history makes it a natural signal. → strongest single line for AI-eng roles.
- *or* **AWS Certified AI Practitioner** (~$100) **+ AWS Generative AI Essentials** (newer, Bedrock/RAG/agents) if your target companies are AWS-shops.

## Part 4 — Certs ranked (cost · effort · why)

1. **Azure AI-102** — ~$165 · 3–4 wks · *the* anchor for applied-AI; MS synergy.
2. **DeepLearning.AI short courses** — free/cheap · ongoing · the actual skills + Piece 3.
3. **Hugging Face courses** — free · the open-source AI fluency signal.
4. **Azure AI-900** — ~$99 · 1–2 wks · quick foundational win.
5. **freeCodeCamp** (React/JS) — free · projects = portfolio.
6. *Optional:* **AWS AI Practitioner + GenAI Essentials**, **Meta Front-End Cert**.

## What NOT to waste time on
- ❌ ML-research / heavy-math certs (PhD-track modeling) — wrong lane for you.
- ❌ Collecting 5+ certs. One anchor (AI-102) + shipped projects beats a wall of badges.
- ❌ Endless learning before shipping. **Ship Piece 1 in week 1** — momentum compounds.

## The 80/20 (if you do only three things)
1. **Write up Apply Board this week** (Piece 1).
2. **Ship one applied-AI product** (Piece 3) via the DeepLearning.AI path.
3. **Pass Azure AI-102.**
