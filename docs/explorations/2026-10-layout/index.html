Layout explorations: three directions

Design exploration only, no app code. Each direction is built around one repeatable loop, starting from Companies, and mocked at phone width (390) with a desktop frame (1440) for Companies. Everything is HDS 0.24.1 tokens: graphite accent, Plus Jakarta Sans, the HDS type ramp. Sample data is invented.

What we are fixing (live main, 390)

  • Discover stacks 5 rows before content: title, orphaned Manage + "+", a track Combobox that repeats the title, the location button, a 6-way tool switch.
  • Three nav layers stacked: app tabs, tool switch, "Your sections" tabs.
  • Every tool repeats an intro paragraph and "Searching in Remote + Spokane, Any mode".
  • Tile cards: big padding, a full-width Details row, three button styles in one row, coloured pills top right.
  • Live: 8+ controls and 3 stacked segmented controls before any result; Save sits above the tag above the snippet.
  • Boards / Teams: mismatched control widths and heights; disabled primary buttons read as empty boxes.
  • Today: Insights card with huge inner padding; inconsistent section heads.
  • Templates: full-width secondary "New snippet"; preview runs "[Company]Hi [Contact]," together (bug, filed as #207).
  • Header: an unexplained dot next to Account.

Adrian's input, applied to all three: one obvious loop you can repeat for the next job; Companies (teams with open roles, plus starred dream companies with a one-button check) is the home screen; fewer routes, fewer tabs (no Today; follow-ups live in the Pipeline); none of the old card patterns (input-looking titles, rows of tinted Copy / Pin / Duplicate / Delete buttons, a "Snippet text" disclosure); the app name never competes with page titles (a small mark on phone, a 16px wordmark in the desktop app bar; the page title is the largest type on every screen); HDS docs-site spacing (24 gutter and card padding, 32 between cards, 24 under a heading, 48 between sections). Assumed from parallel PRs: Insights moves to the Pipeline, status dots are gone, tables are restyled in HDS, HDS spacing is raised.

The loop every direction is built on

  1. FindCompanies hiring now, or check your starred ones
  2. SavePick a role on the company, one Save
  3. ApplyPipeline "To apply": open it, send it, Mark applied
  4. Follow upDue follow-ups sit in the Pipeline; Log resets the clock

The Pipeline always ends with "Find the next company", so the loop starts again. Live postings, Boards and Teams stop being separate tools: open roles live on each company, and finding new companies is one "Add a company" action.

A makes Companies home and keeps the loop on three screens. It is built from parts we already ship (the Teams tool, By company, Pipeline rows). C's Apply sheet puts templates where you use them, so the Templates tab can go later (down to 2 tabs). B's rail takes the extra width at ≥ lg.
