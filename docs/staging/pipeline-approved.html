The exact changes

  1. Upgrade to HDS 0.29. Sora 700 headings, weights only 700 and 500, no italic anywhere. The empty-state titles are italic today.
  2. Compact spacing for apps. Steps of 4, 8, 12, 16, 24 and 32, body 15, captions 13. 0.29's airier scale stays for sites. This is new in HDS as a density setting (data-density="compact") so Ops can use it too.
  3. A primary that looks like one. Solid light fill in dark mode (dark fill in light mode), bold label. Today it's a grey that reads as disabled.
  4. One banner at most. "Saved in this browser only" becomes a dot on the account button, with Sign in inside the menu. Sample data becomes one muted line with a Clear link.
  5. Panels, not floating text. To apply, Follow up and Next 7 days each sit on a raised surface with a header and rows. On desktop they go two columns, so the page isn't one long black strip.
  6. Rows read as content. Titles are white and medium weight, without underlines. Each row has one 36px secondary action on the right, and every button on a page is the same height.
  7. One left edge. No indented ghost buttons or floating close buttons. Every block starts on the same line.

Guardrails so it doesn't drift again

  • HDS freshness test. Roleforge fails its build if it falls more than one minor version behind the latest HDS. It fell three behind without anyone noticing.
  • Screenshot baselines. Today, Pipeline, Discover and Templates at 390 and 1440, light and dark, with sample data. Any change to the pixels has to be approved in the PR, so a layout break can't slip through on green tests.
  • Layout rules as tests (e2e, every route):
    • at most one primary button and one banner above the page head
    • every top-level block shares the same left edge
    • buttons on one page share one height
    • no italic, no underlined titles
  • Spec before code for UI. Any change to a page's layout starts as a staging preview like this one. The reviewer checks the screenshots against it before approving.

Reply "go" to build it. One builder adds the compact density to HDS, the next upgrades Roleforge and adds the guardrails. You get a preview link to check before anything goes live.
