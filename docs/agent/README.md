# Agent docs

Detail for the rules in [`CLAUDE.md`](../../CLAUDE.md). One subject per file. Read only the file for the area you change.

- [`brand.md`](brand.md): The product name, the flame logo, its motion, the boot splash and the sign-in screen brand.
- [`hds.md`](hds.md): How the app uses `@hirobius/design-system` (HDS): components, `sx`, density, theme, lint and polish rules.
- [`shell.md`](shell.md): The two screens, the app bar, the Account menu, routes, return paths, focus, scroll, empty states and action feedback.
- [`review.md`](review.md): The posting list, its window, the full description and Daily picks.
- [`apply.md`](apply.md): The saved list, named views, Add job, Export links and the tracker model.
- [`job-view.md`](job-view.md): The job page: keys by state, the action dock, title block, notes, links, dates, the Company page and posting links.
- [`surfaces.md`](surfaces.md): Card rules, list rows, the posting card, page width, outlines and the selected fill.
- [`documents.md`](documents.md): The Documents dialog, the editor, templates and variables.
- [`data.md`](data.md): The store, the synced blob and its versions, first run and what a new user sees.
- [`feed.md`](feed.md): How postings are read, matched, scored, deduped and scanned, in the browser and on the server.
- [`account.md`](account.md): Sign-in guards, OAuth, Privacy and terms, crash reports, the installable app and stale tabs.
- [`build.md`](build.md): Build budget, CI, the deploy gate, CSP, guardrails, screenshots and repo notes.
- [`history.md`](history.md): Notes on screens and models that were replaced. Read these only to understand old data or old links. The current rules are in the other files.
